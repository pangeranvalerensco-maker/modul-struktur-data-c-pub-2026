    # Modul Struktur Data Bahasa C - PUB

Repositori ini merupakan pendamping kode untuk **Modul Struktur Data Bahasa C** dalam Program Beasiswa **Pemberdayaan Umat Berkelanjutan (PUB)**.

Repositori berisi contoh program, implementasi struktur data, latihan, dan kode pendukung yang digunakan dalam pembelajaran Struktur Data menggunakan bahasa C.

## Tentang Modul

Modul ini disusun untuk membantu peserta memahami konsep dan implementasi struktur data secara bertahap menggunakan bahasa C.

Pembelajaran tidak hanya berfokus pada penulisan sintaks, tetapi juga pada pemahaman cara kerja struktur data, proses pengolahan data, serta penerapannya dalam penyelesaian masalah.

Materi dalam repositori mengikuti pembahasan yang terdapat dalam modul, mulai dari struktur data dasar hingga penerapannya dalam sebuah program.

## Materi

Kode dalam repositori disusun berdasarkan bab atau topik yang terdapat dalam modul.

Materi utama meliputi:

- Array
- `struct`
- Pointer
- Singly Linked List
- Doubly Linked List
- Stack
- Queue
- File Handling
- Validasi Data
- Sorting Dasar
- Sorting Lanjutan
- Searching
- Tree
- Graph
- Implementasi struktur data dalam program
